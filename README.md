# TaskBoardLite

TaskBoardLite - отдельное desktop-приложение для учебной практики за 1-3 день.
Программа предназначена для учета складских задач и заявок.

## Возможности

- добавление заявки с названием, местом, приоритетом и статусом;
- сохранение заявок в SQLite-базе `taskboard_lite.db`;
- поиск по названию и месту;
- удаление выбранной заявки;
- изменение статуса выбранной заявки на `Готово`;
- модульные тесты для слоя хранения.

## Запуск

```bash
python main.py
```

## Тесты

```bash
python -m unittest test_storage.py
```
